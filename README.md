# Discord Anti-Raid Bot 🛡️

Bot anti-raid profissional para Discord com painel online integrado. Otimizado para consumir no máximo 75-80MB de RAM.

## Features ✨

- ✅ Detecção avançada de raids
- ✅ Painel online em tempo real
- ✅ Proteção contra spam
- ✅ Sistema de verificação de membros
- ✅ Logs detalhados
- ✅ Configuração por servidor
- ✅ Otimizado para baixíssimo consumo de RAM

## Estrutura do Projeto

```
├── bot/               # Bot Discord
├── dashboard/         # Painel web
├── database/          # Configurações e logs
└── docs/              # Documentação
```

## Instalação Rápida

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Configure o `.env`
4. Inicie o bot: `npm start`
5. Acesse o painel: `http://localhost:3000`

## Requisitos

- Node.js 16+
- Discord.js 14
- Express.js
- SQLite (leve)
